# 🚀 Stellar Base — Космический симулятор

**Stellar Base** — оффлайн-игра для Android о выживании и строительстве в открытом космосе.
Играй за капитана Шепарда, исследуй 4 уникальные планеты, добывай ресурсы и строй базу мечты.

---

## 🎮 Геймплей

- **Открытый мир** — 4 планеты с уникальными биомами и ресурсами
- **Строительство** — возведи любую базу из 12+ объектов
- **Автоматизация** — авто-шахтёры, солнечные панели, фабрикаторы
- **Прокачка** — дерево улучшений: скафандр, корабль, база, автоматизация
- **Выживание** — следи за кислородом
- **Вид от первого лица** — горизонтальный режим

## 🌍 Планеты

| Планета | Ресурсы |
|---------|---------|
| Марс-Альфа | Железо, кремний, вода |
| Ледяной Европа-7 | Вода, кремний, кристаллы |
| Вулканический Ио-X | Железо, титан, кристаллы |
| Газовый Нептун-Омега | Кремний, энергия, кристаллы |

## 📱 Установка APK

1. Перейди во вкладку **Actions** → выбери последний успешный запуск
2. Скачай **stellar-base-apk** из артефактов
3. Разреши установку из неизвестных источников на телефоне
4. Установи APK

## 🛠️ Технологии

- **Движок**: Godot 4.3
- **Язык**: GDScript
- **Платформа**: Android arm64-v8a
- **Сборка**: GitHub Actions (автоматическая при каждом push)

## 📁 Структура

```
stellar-base-game/
├── .github/workflows/build-android.yml   # Автосборка APK

│   ├── build_system.gd                   # Система строительства

│   └── buildings/                        # Скрипты построек

```
